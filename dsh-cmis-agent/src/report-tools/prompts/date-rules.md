# 日期表达识别
系统支持以下日期表达式，用于查询：
1. 日期区间查询：
   - 两个日期之间的记录，如"4月1日到4月10日的报表"
   - 相对日期查询，如"昨天到今天的数据"、"前天到今天的数据"

2. 相对日期表达：
   - 今天：当前日期（如 2025-01-15）
   - 昨天：当前日期前1天
   - 前天：当前日期前2天
   - 大前天：当前日期前3天
   - 本周：本周一到今天
   - 上周：上周一到上周日

3. 日期范围表达：
   - "最近X天"：当前日期前X天到今天
   - "本月"：本月1日到今天
   - "上个月"：上个月1日到上个月最后一天
